BLDC Balance HMI

Control por UART — protocolo MODE / M1 / M2 / SET / PID / STOP
Desconectado
Este navegador no soporta Web Serial API. Usa Chrome o Edge de escritorio, y abre este archivo directamente (doble clic) o sírvelo por http://localhost.

Modo de control

MAXPCT:<pct> — limita ambos ESC sin importar el modo. 30% es el valor que se comprobó seguro en banco.

Control de velocidad (%)

Mueve el slider o escribe el valor y pulsa "Enviar" — no se manda nada hasta que lo pidas. 0..100 — los ESC son unidireccionales, sin reversa.

Control PID de balance

Nada se envía mientras editas los campos — solo al pulsar el botón.
